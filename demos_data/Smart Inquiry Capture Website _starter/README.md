# 🎉 Smart Inquiry Capture Website

## ✨ Project Overview

A **premium, production-ready** website for the Smart Inquiry Capture service. This project features a stunning design, smooth animations, and full functionality to capture incoming inquiries, qualify leads automatically, and convert high-intent prospects into scheduled appointments.

---

## 📦 What's Included

### 1. **Main Landing Page** (`index.html`)
   - **Hero Section** with animated gradient orbs and compelling CTA
   - **Features Grid** showcasing 6 core capabilities
   - **How It Works** timeline with 4-step process
   - **Pricing Section** with 3 detailed tiers (Starter, Business, Professional)
   - **Testimonials** from satisfied clients
   - **FAQ Accordion** with common questions
   - **CTA Section** with WhatsApp integration
   - **Contact Form** with validation
   - **Professional Footer** with navigation

### 2. **Booking Demo Page** (`booking.html`)
   - **5-Step Wizard Flow**:
     1. Select Plan (Starter/Business/Professional)
     2. Choose Date (interactive calendar)
     3. Pick Time (available slots)
     4. Enter Details (contact form)
     5. Confirm Booking (summary review)
   - **Success Animation** after booking confirmation
   - **Progress Indicator** showing current step
   - **Form Validation** with real-time feedback
   - **State Management** preserving selections

### 3. **Styles & Design** (`styles.css`)
   - **Design System** with CSS variables
   - **Vibrant Color Palette** with gradients
   - **Premium Typography** (Inter + Outfit fonts)
   - **Responsive Breakpoints** for all devices
   - **Smooth Animations** and micro-interactions
   - **Glassmorphism Effects** on navigation
   - **Accessibility Features** (WCAG compliant)

### 4. **Functionality** (`script.js` + `booking.js`)
   - **Smooth Scroll** navigation
   - **Mobile Menu** toggle
   - **FAQ Accordion** functionality
   - **Form Validation** with notifications
   - **Intersection Observer** for scroll animations
   - **Booking Flow** state management
   - **Calendar Generation** (next 3 weeks)
   - **Keyboard Navigation** support
